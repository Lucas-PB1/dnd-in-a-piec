# Estilo de Luta do Guerreiro (faltante)

## Falta
- PHB 2024: Guerreiro escolhe **Estilo de Luta** cedo (feat de Fighting Style) — ainda **não existe** no jogo.
- Escolha na criação ou no nível adequado; efeitos dos estilos úteis no side-scroller (Arqueira, Duelo, Defesa, Proteção, Duas Armas, etc. — subset jogável).
- Compêndio / save / tela de escolha.
