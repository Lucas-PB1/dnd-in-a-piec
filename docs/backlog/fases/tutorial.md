# Fase tutorial (como jogar)

## Feito (fatias 1–3)
- Fase **Treino** antes da Clareira: sem inimigos; todo Novo Jogo entra nela; porta → Clareira.
- Placas: andar/pular, baú, loja, J/K, arco, **Fôlego (F)**, **Surto (R, nv 2+)**, porta.
- Baú → loja → boneco com folga E ≥96 px; **50 po** ao criar; **−4 PV** para praticar Fôlego.
- Teste `teste_tutorial`.

## Falta
- (opcional) pedra de perícia no Treino; mais polish de textos.

## Pronto quando
- Novo jogo passa pelo tutorial e o jogador consegue os controles básicos sem ler código; testes de presença/fluxo.
