# Docs (Diátaxis)

Documentação do **DnD in a Piece**, organizada no [Diátaxis](https://diataxis.fr/):

| Pasta / arquivo | Papel Diátaxis | Para quê |
|---|---|---|
| `adr/` | Explanation | Decisões por tema (ADRs). Viram rules do Cursor. |
| `how-to/` | How-to | Receitas passo a passo (criatura, arma, teste…). |
| `reference/` | Reference | Mapa do sistema, artes prontas, export Android, talentos. |
| `backlog/` | — | **O que falta** (1 arquivo = 1 pendência). Fonte do `/proxima-fatia`. |
| `CHANGELOG.md` | — | O que já foi feito (append-only). |
| `spritecook/` | Reference | Prompts vivos do SpriteCook. |

Índice curto para agentes: **`CLAUDE.md`** na raiz do repo. Skills de código: `.claude/skills/godot-*`.

**Não há** pasta `arquivo/` nem doc monolítico de pendências: morto sai do repo; aberto fica no `backlog/`.
